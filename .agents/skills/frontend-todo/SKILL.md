# Frontend Todo Skill

## Rules

- Separate logic into modules
- Keep functions small
- Use semantic naming
- Use localStorage persistence
- Avoid duplicated code
- Prefer reusable functions

## Architecture

src/
 ├── js/
 │   ├── app.js
 │   ├── storage.js
 │   ├── ui.js
 │   └── events.js

## Workflow

1. Analyze structure
2. Refactor duplicated logic
3. Separate responsibilities
4. Improve readability
5. Optimize event handling
